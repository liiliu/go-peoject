# 参数验证使用指南

## 📋 概述

项目已集成 `go-playground/validator` 并封装了友好的验证器工具，支持多种方式自定义错误提示。

---

## 🎯 三种自定义提示方式

### 方法一：使用 label 标签（推荐）

最简单的方式，在结构体中添加 `label` 标签：

```go
type LoginRequest struct {
    Username string `json:"username" label:"用户名" validate:"required,min=3,max=50"`
    Password string `json:"password" label:"密码" validate:"required,min=6"`
}
```

**在接口中使用**：

```go
func Login(c *fiber.Ctx) error {
    var req request.LoginRequest
    if err := c.BodyParser(&req); err != nil {
        return c.JSON(view.ErrorResult(view.CodeInvalidBody))
    }
    
    // 验证参数
    if err := validator.Validate(&req); err != nil {
        return c.JSON(view.ErrorResultWithMsg(view.CodeInvalidParams, validator.GetErrorMsg(err)))
    }
    
    // 业务逻辑...
}
```

**错误提示**：
```
"用户名 不能为空"
"用户名 长度不能少于 3"
"密码 长度不能少于 6"
```

---

### 方法二：自定义错误消息 map

完全自定义每个字段、每条规则的错误消息：

```go
func Register(c *fiber.Ctx) error {
    var req request.RegisterRequest
    if err := c.BodyParser(&req); err != nil {
        return c.JSON(view.ErrorResult(view.CodeInvalidBody))
    }
    
    // 自定义错误消息
    customMsg := map[string]string{
        "username.required": "请输入用户名",
        "username.min":      "用户名至少需要3个字符",
        "username.max":      "用户名最多50个字符",
        "password.required": "请输入密码",
        "password.min":      "密码长度至少6位",
        "email.email":       "邮箱格式不正确，请检查",
        "phone.len":         "手机号必须是11位数字",
    }
    
    // 使用自定义消息验证
    if err := validator.ValidateWithMsg(&req, customMsg); err != nil {
        return c.JSON(view.ErrorResultWithMsg(view.CodeInvalidParams, err.Error()))
    }
    
    // 业务逻辑...
}
```

**消息格式**：
- `"字段名.规则"` - 针对特定字段的特定规则
- `"字段名"` - 针对字段的所有规则（通用提示）

---

### 方法三：修改默认提示模板

修改 `library/validator/validator.go` 中的 `getFieldError` 函数：

```go
func getFieldError(fieldError validator.FieldError) string {
    field := fieldError.Field()
    tag := fieldError.Tag()

    switch tag {
    case "required":
        return fmt.Sprintf("请输入%s", field)  // 自定义格式
    case "min":
        return fmt.Sprintf("%s至少需要%s个字符", field, fieldError.Param())
    case "email":
        return fmt.Sprintf("请输入正确的%s格式", field)
    // ... 更多规则
    }
}
```

## 📚 完整示例

### 示例 1：用户注册（使用 label）

**定义请求结构**：

```go
// app/request/user.go
package request

type RegisterRequest struct {
    Username string `json:"username" label:"用户名" validate:"required,min=3,max=50,alphanum"`
    Password string `json:"password" label:"密码" validate:"required,min=6,max=100"`
    Email    string `json:"email" label:"邮箱" validate:"required,email"`
    Phone    string `json:"phone" label:"手机号" validate:"omitempty,len=11,numeric"`
    Age      int    `json:"age" label:"年龄" validate:"omitempty,gte=18,lte=120"`
    RealName string `json:"real_name" label:"真实姓名" validate:"omitempty,min=2,max=20"`
}
```

**接口实现**：

```go
// app/api/v1/user/register.go
func Register(c *fiber.Ctx) error {
    var req request.RegisterRequest
    if err := c.BodyParser(&req); err != nil {
        return c.JSON(view.ErrorResult(view.CodeInvalidBody))
    }
    
    if err := validator.Validate(&req); err != nil {
        return c.JSON(view.ErrorResultWithMsg(view.CodeInvalidParams, validator.GetErrorMsg(err)))
    }
    
    // 业务逻辑...
    return c.JSON(view.SuccessResult(nil))
}
```

## 🏷️ 常用验证规则

### 字符串规则

```go
type Example struct {
    Field1 string `validate:"required"`           // 必填
    Field2 string `validate:"min=3"`              // 最小长度
    Field3 string `validate:"max=100"`            // 最大长度
    Field4 string `validate:"len=11"`             // 固定长度
    Field5 string `validate:"email"`              // 邮箱格式
    Field6 string `validate:"url"`                // URL格式
    Field7 string `validate:"alphanum"`           // 字母+数字
    Field8 string `validate:"numeric"`            // 纯数字
    Field9 string `validate:"alpha"`              // 纯字母
}
```

### 数字规则

```go
type Example struct {
    Field1 int     `validate:"required"`          // 必填
    Field2 int     `validate:"min=1"`             // 最小值
    Field3 int     `validate:"max=100"`           // 最大值
    Field4 int     `validate:"gte=18"`            // 大于等于
    Field5 int     `validate:"lte=120"`           // 小于等于
    Field6 int     `validate:"gt=0"`              // 大于
    Field7 int     `validate:"lt=999"`            // 小于
    Field8 float64 `validate:"required,gt=0"`     // 必填且大于0
}
```

### 组合规则

```go
type Example struct {
    Username string `validate:"required,min=3,max=50,alphanum"`
    Password string `validate:"required,min=6,max=100"`
    Age      int    `validate:"omitempty,gte=18,lte=120"`
    Email    string `validate:"omitempty,email"`
}
```

### 特殊规则

```go
type Example struct {
    Field1 string `validate:"omitempty"`          // 可选字段
    Field2 string `validate:"required_without=Field3"` // Field3为空时必填
    Field3 string `validate:"required_with=Field2"`    // Field2不为空时必填
    Field4 string `validate:"eqfield=Password"`        // 必须等于Password字段
}
```

## 💡 最佳实践

### 1. 优先使用 label 标签

简单场景直接用 label，代码清晰：

```go
type LoginRequest struct {
    Username string `json:"username" label:"用户名" validate:"required,min=3"`
    Password string `json:"password" label:"密码" validate:"required,min=6"`
}
```

### 2. 复杂场景使用自定义消息

需要更详细提示或业务相关提示时使用：

```go
customMsg := map[string]string{
    "username.min": "用户名至少3个字符，建议使用英文字母",
    "password.min": "为了账号安全，密码至少需要6位",
}
```

### 3. 统一错误处理

可以封装一个辅助函数：

```go
// library/validator/helper.go
func ValidateRequest(c *fiber.Ctx, req interface{}) error {
    if err := c.BodyParser(req); err != nil {
        return c.JSON(view.ErrorResult(view.CodeInvalidBody))
    }
    
    if err := Validate(req); err != nil {
        return c.JSON(view.ErrorResultWithMsg(view.CodeInvalidParams, GetErrorMsg(err)))
    }
    
    return nil
}
```

**使用**：

```go
func Login(c *fiber.Ctx) error {
    var req request.LoginRequest
    if err := validator.ValidateRequest(c, &req); err != nil {
        return err
    }
    
    // 业务逻辑...
}
```

## ⚠️ 注意事项

1. **label 优先级**：`label` > `json` > 字段名
2. **自定义消息格式**：必须是 `"字段名.规则"` 格式
3. **多条错误**：会用分号 `;` 连接多条错误消息
4. **omitempty**：字段可选，为空时不验证
