# 部署说明

## 📦 部署方式

项目支持多种部署方式：

1. **一键部署脚本** - 自动化部署到服务器（推荐）
2. **Docker 部署** - 容器化部署
3. **手动部署** - 传统部署方式

---

## 🚀 一键部署（推荐）

### 测试环境部署

```bash
bash yun-test.sh
```

### 生产环境部署

```bash
bash yun-prod.sh
```

> **提示**：生产环境部署需要二次确认

---

## 📝 部署脚本说明

### yun-test.sh / yun-prod.sh

**功能**：
- ✅ 自动编译项目
- ✅ 上传到服务器
- ✅ 备份旧版本
- ✅ 重启服务
- ✅ 健康检查

**使用前配置**：

编辑脚本顶部的配置：

```bash
# 服务器配置
SSH_USER="root"
SSH_HOST="your-server-ip"
SSH_PORT="22"

# 项目配置
REMOTE_DIR="/data/server/your_project"
```

## 🔧 服务管理脚本

### restart.sh

部署后在服务器上使用此脚本管理服务。

**启动服务**：
```bash
bash restart.sh start      # 部署并启动所有服务
bash restart.sh run        # 仅启动服务（不部署）
```

**停止服务**：
```bash
bash restart.sh stop       # 停止所有服务
```

**重启服务**：
```bash
bash restart.sh restart    # 重启所有服务
```

**查看状态**：
```bash
bash restart.sh status     # 查看服务状态和资源占用
```

**查看日志**：
```bash
bash restart.sh logs api 100   # 查看 api 最近 100 行日志
bash restart.sh logs job 50    # 查看 job 最近 50 行日志
```

**清理日志**：
```bash
bash restart.sh clean      # 清理过大的日志文件
```

**监控模式**：
```bash
bash restart.sh watch      # 进入监控模式（自动重启异常服务）
```

## 🐳 Docker 部署

### 1. 构建镜像

```bash
docker build -t your_project:latest .
```

### 2. 运行容器

```bash
docker run -d \
  --name your_project_api \
  -p 8080:8080 \
  -v $(pwd)/config:/app/config \
  -v $(pwd)/logs:/app/logs \
  your_project:latest api
```

### 3. 使用 Docker Compose

```bash
# 启动所有服务
docker-compose up -d

# 查看日志
docker-compose logs -f api

# 停止服务
docker-compose down
```

## 🛠️ 手动部署

### 1. 编译项目

```bash
# Linux
make build-linux

# Windows
make build

# macOS
GOOS=darwin GOARCH=amd64 go build -o server main.go
```

### 2. 上传文件

```bash
scp server user@server:/path/to/project/
scp -r config user@server:/path/to/project/
```

### 3. 配置服务

编辑 `config/config.toml`：

```toml
[server]
debug = false
port = 8080

[database]
host = "localhost"
port = 3306
username = "root"
password = "your_password"
database = "your_database"
```

### 4. 启动服务

```bash
# API 服务
nohup ./server api > logs/api.log 2>&1 &

# Job 服务
nohup ./server job > logs/job.log 2>&1 &
```

## ⚠️ 注意事项

### 生产环境

1. **必须修改 JWT Secret**
2. **数据库密码不要使用默认值**
3. **Redis 建议设置密码**
4. **关闭 Debug 模式** (`debug = false`)
5. **配置日志轮转**
6. **定期备份数据库**

### 性能优化

```toml
[server]
read_timeout = 30
write_timeout = 30
max_connections = 10000

[database]
max_idle_conns = 10
max_open_conns = 100
conn_max_lifetime = 3600
```

## 🔍 故障排查

### 服务无法启动

```bash
# 查看日志
tail -f logs/api.log

# 检查端口占用
netstat -tlnp | grep 8080

# 检查进程
ps aux | grep server
```

### 数据库连接失败

```bash
# 测试数据库连接
mysql -h localhost -u root -p

# 检查防火墙
firewall-cmd --list-all
```

### Redis 连接失败

```bash
# 测试 Redis 连接
redis-cli ping

# 检查 Redis 状态
systemctl status redis
```
