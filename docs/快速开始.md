# 快速开始

## 📋 环境要求

- Go 1.22+
- MySQL 5.7+
- Redis 5.0+

---

## 🚀 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/your/starter_template.git
cd starter_template
```

### 2. 安装依赖

```bash
go mod tidy
```

### 3. 配置文件

复制配置文件并修改：

```bash
cp config/config.toml.example config/config.toml
```

修改 `config/config.toml`：

```toml
# 数据库配置
[database]
host = "127.0.0.1"
port = 3306
username = "root"
password = "your_password"
database = "starter_db"

# Redis 配置
[redis]
host = "127.0.0.1"
port = 6379
password = ""
db = 0

# JWT 配置
[jwt]
secret = "your-secret-key"
expire = 86400  # 24小时
```

### 4. 创建数据库

```sql
CREATE DATABASE starter_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 5. 运行项目

#### 启动 API 服务

```bash
go run main.go api
```

服务将运行在 `http://localhost:8080`

#### 启动定时任务

```bash
go run main.go job
```

#### 查看帮助

```bash
go run main.go --help
```

## 🎯 第一个 API

### 1. 创建数据模型

创建 `app/model/user.go`：

```go
package model

import (
    "gorm.io/gorm"
    "time"
)

type User struct {
    ID        uint           `gorm:"primarykey" json:"id"`
    Username  string         `gorm:"size:50;not null;unique" json:"username"`
    Email     string         `gorm:"size:100;not null;unique" json:"email"`
    Password  string         `gorm:"size:100;not null" json:"-"`
    Status    int            `gorm:"default:1" json:"status"`
    CreatedAt time.Time      `json:"created_at"`
    UpdatedAt time.Time      `json:"updated_at"`
    DeletedAt gorm.DeletedAt `gorm:"index" json:"-"`
}
```

### 2. 创建请求/响应结构

创建 `app/api/v1/user/request.go`：

```go
package user

type CreateUserRequest struct {
    Username string `json:"username" validate:"required,min=3,max=20"`
    Email    string `json:"email" validate:"required,email"`
    Password string `json:"password" validate:"required,min=6"`
}
```

### 3. 创建控制器

创建 `app/api/v1/user/user.go`：

```go
package user

import (
    "github.com/gofiber/fiber/v2"
    "your_project/app/model"
    "your_project/library/database"
    "your_project/library/validator"
)

// CreateUser 创建用户
func CreateUser(c *fiber.Ctx) error {
    var req CreateUserRequest
    
    // 解析参数
    if err := c.BodyParser(&req); err != nil {
        return c.Status(400).JSON(fiber.Map{
            "code": 400,
            "msg":  "参数解析失败",
        })
    }
    
    // 验证参数
    if err := validator.Validate.Struct(req); err != nil {
        return c.Status(400).JSON(fiber.Map{
            "code": 400,
            "msg":  validator.TranslateError(err),
        })
    }
    
    // 创建用户
    user := &model.User{
        Username: req.Username,
        Email:    req.Email,
        Password: req.Password, // 实际应该加密
    }
    
    if err := database.DB.Create(user).Error; err != nil {
        return c.Status(500).JSON(fiber.Map{
            "code": 500,
            "msg":  "创建失败",
        })
    }
    
    return c.JSON(fiber.Map{
        "code": 200,
        "msg":  "创建成功",
        "data": user,
    })
}

// GetUser 获取用户
func GetUser(c *fiber.Ctx) error {
    id := c.Params("id")
    
    var user model.User
    if err := database.DB.First(&user, id).Error; err != nil {
        return c.Status(404).JSON(fiber.Map{
            "code": 404,
            "msg":  "用户不存在",
        })
    }
    
    return c.JSON(fiber.Map{
        "code": 200,
        "data": user,
    })
}

// ListUsers 用户列表
func ListUsers(c *fiber.Ctx) error {
    page := c.QueryInt("page", 1)
    size := c.QueryInt("size", 10)
    
    var users []model.User
    var total int64
    
    database.DB.Model(&model.User{}).Count(&total)
    database.DB.Limit(size).Offset((page - 1) * size).Find(&users)
    
    return c.JSON(fiber.Map{
        "code": 200,
        "data": fiber.Map{
            "list":  users,
            "total": total,
            "page":  page,
            "size":  size,
        },
    })
}
```

### 4. 注册路由

在 `commands/api/api.go` 中注册路由：

```go
// 用户路由
userGroup := v1.Group("/user")
userGroup.Post("/", user.CreateUser)
userGroup.Get("/:id", user.GetUser)
userGroup.Get("/", user.ListUsers)
```

## 🔧 常见问题

### 1. 数据库连接失败

检查：
- MySQL 是否启动
- 配置文件中的数据库信息是否正确
- 数据库是否已创建

### 2. Redis 连接失败

检查：
- Redis 是否启动
- 配置文件中的 Redis 信息是否正确

### 3. 端口被占用

修改 `config/config.toml` 中的端口：

```toml
[server]
port = 8081  # 改为其他端口
```
