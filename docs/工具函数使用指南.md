# 工具函数使用指南

## 📋 概述

`library/util/util.go` 提供了丰富的工具函数，涵盖字符串、切片、加密、随机、类型转换、JSON、验证等常用功能。

---

## 🎯 功能分类

| 分类 | 函数数量 | 说明 |
|------|---------|------|
| **字符串工具** | 13个 | 判空、截取、转换、遮罩等 |
| **切片工具** | 7个 | 去重、分块、判断包含 |
| **加密工具** | 2个 | MD5、SHA256 |
| **随机工具** | 5个 | 随机字符串、数字、订单号 |
| **类型转换** | 5个 | 字符串与各类型互转 |
| **JSON 工具** | 3个 | 序列化、反序列化 |
| **验证工具** | 5个 | 邮箱、手机、URL 等验证 |
| **通用工具** | 6个 | 三元运算、最大最小值等 |

## 📚 详细说明

### 1. 字符串工具

#### 判空与检查

```go
// 判断字符串是否为空（去除空格后）
util.IsEmpty("  ")          // true
util.IsEmpty("hello")       // false

// 判断字符串是否不为空
util.IsNotEmpty("hello")    // true

// 检查是否包含子串
util.Contains("hello world", "world")  // true

// 检查前缀/后缀
util.HasPrefix("hello.txt", "hello")   // true
util.HasSuffix("hello.txt", ".txt")    // true
```

#### 字符串操作

```go
// 截取字符串（支持中文）
util.Substring("你好世界", 0, 2)  // "你好"

// 反转字符串
util.ReverseString("hello")      // "olleh"

// 去除两端空格
util.TrimSpace("  hello  ")      // "hello"
```

#### 命名风格转换

```go
// 驼峰转蛇形
util.CamelToSnake("UserName")    // "user_name"
util.CamelToSnake("userId")      // "user_id"

// 蛇形转驼峰
util.SnakeToCamel("user_name")   // "UserName"
util.SnakeToCamel("user_id")     // "UserId"
```

#### 遮罩敏感信息

```go
// 遮罩手机号
util.MaskString("13812345678", 3, 4, "*")  // "138****5678"

// 遮罩身份证
util.MaskString("320123199001011234", 6, 4, "*")  // "320123********1234"

// 遮罩邮箱
email := "user@example.com"
parts := strings.Split(email, "@")
masked := util.MaskString(parts[0], 2, 0, "*") + "@" + parts[1]
// "us*****@example.com"
```

### 2. 切片工具

#### 判断包含

```go
// 判断字符串是否在切片中
roles := []string{"admin", "user", "guest"}
util.InStringSlice("admin", roles)  // true

// 判断整数是否在切片中
ids := []int{1, 2, 3, 4, 5}
util.InIntSlice(3, ids)  // true
```

#### 去重

```go
// 字符串切片去重
tags := []string{"go", "java", "go", "python", "java"}
unique := util.UniqueStrings(tags)  // ["go", "java", "python"]

// 整数切片去重
numbers := []int{1, 2, 2, 3, 3, 3}
unique := util.UniqueInts(numbers)  // [1, 2, 3]
```

#### 切片分块

```go
// 字符串切片分块
users := []string{"user1", "user2", "user3", "user4", "user5"}
chunks := util.StringSliceChunk(users, 2)
// [["user1", "user2"], ["user3", "user4"], ["user5"]]

// 通用切片分块
items := []interface{}{1, 2, 3, 4, 5}
chunks := util.SliceChunk(items, 2)
// [[1, 2], [3, 4], [5]]
```

### 4. 随机工具

#### 随机字符串


**使用场景**：
- 生成验证码
- 生成订单号

### 7. 验证工具

#### 邮箱验证

```go
util.IsEmail("user@example.com")    // true
util.IsEmail("invalid-email")       // false
```

#### 手机号验证（中国大陆）

```go
util.IsMobile("13812345678")    // true
util.IsMobile("12312345678")    // false（第二位不是3-9）
util.IsMobile("1381234567")     // false（长度不够）
```

#### URL 验证

```go
util.IsURL("https://example.com")        // true
util.IsURL("http://example.com:8080")    // true
util.IsURL("example.com")                // false（缺少协议）
```

#### 身份证验证

```go
util.IsIDCard("320123199001011234")  // true（简单格式验证）
```

#### 正则匹配

```go
// 匹配多个正则表达式中的任意一个
patterns := []string{
    `^\d{11}$`,       // 11位数字
    `^[a-z]+@.*\.com$`, // 邮箱
}
util.RegexpMatchSlice("13812345678", patterns)  // true
```

### 8. 通用工具

#### 三元运算符

```go
// 泛型版本，支持任意类型
age := 20
status := util.Ternary(age >= 18, "成年", "未成年")  // "成年"

price := 100
discount := util.Ternary(price > 50, 0.8, 1.0)  // 0.8
```

#### 默认值

```go
// 字符串默认值
name := util.DefaultString("", "匿名用户")  // "匿名用户"
name := util.DefaultString("张三", "匿名用户")  // "张三"

// 整数默认值
pageSize := util.DefaultInt(0, 10)   // 10
pageSize := util.DefaultInt(20, 10)  // 20
```

#### 数学运算

```go
// 最小值
min := util.Min(5, 10)  // 5

// 最大值

// 绝对值

```

## 💡 实战示例

### 示例 1：用户注册验证

```go
func Register(username, email, mobile string) error {
    // 验证用户名
    if util.IsEmpty(username) {
        return errors.New("用户名不能为空")
    }
    
    // 验证邮箱
    if !util.IsEmail(email) {
        return errors.New("邮箱格式不正确")
    }
    
    // 验证手机号
    if !util.IsMobile(mobile) {
        return errors.New("手机号格式不正确")
    }
    
    // 生成密码盐值
    salt := util.RandomString(16)
    
    // ... 保存用户
    return nil
}
```

### 示例 2：生成验证码并发送短信

```go
func SendSmsCode(mobile string) error {
```

### 示例 5：批量处理

```go
func SendBatchEmail(emails []string, subject, body string) {
    // 去重
    emails = util.UniqueStrings(emails)
    
    // 分批发送（每批100个）
    chunks := util.StringSliceChunk(emails, 100)
    
    for _, chunk := range chunks {
        for _, email := range chunk {
            if util.IsEmail(email) {
                email.Send(email, subject, body)
            }
        }
    }
}
```

## ⚠️ 注意事项

1. **密码加密**：MD5 不够安全，生产环境建议使用 `bcrypt`
2. **随机数安全**：涉及安全的场景应使用 `crypto/rand`
3. **验证工具**：仅做格式验证，实际业务需要更严格的校验
4. **类型转换**：转换失败返回零值，不会返回错误
