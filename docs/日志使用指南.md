# 日志使用指南

## 📋 概述

项目使用 **zap** 作为日志库，提供高性能、结构化的日志记录功能。

---

## 🚀 快速开始

### 基础使用

```go
import "your_project/library/logger"

// Info 日志
logger.Info("user", "用户登录成功，ID: %d", userID)

// Error 日志
logger.Error("db", "数据库查询失败: %v", err)

// Warn 日志
logger.Warn("cache", "缓存未命中: %s", key)

// Debug 日志（仅开发环境）
logger.Debug("api", "请求参数: %+v", req)
```

---

## 📝 日志级别

### 级别说明

| 级别 | 使用场景 | 示例 |
|------|---------|------|
| **Debug** | 调试信息（仅开发） | 打印变量值、函数调用 |
| **Info** | 一般信息 | 用户操作、系统事件 |
| **Warn** | 警告信息 | 缓存未命中、降级处理 |
| **Error** | 错误信息 | 数据库错误、API调用失败 |
| **Fatal** | 致命错误（程序退出） | 初始化失败 |

### 使用示例

```go
// Debug - 调试信息
logger.Debug("auth", "Token 解析结果: %+v", claims)

// Info - 操作日志
logger.Info("user", "用户注册成功, ID: %d, Username: %s", user.ID, user.Username)

// Warn - 警告
logger.Warn("ratelimit", "用户 %d 请求频率过高", userID)

// Error - 错误
if err := database.DB.Create(&user).Error; err != nil {
    logger.Error("db", "创建用户失败: %v", err)
    return err
}

// Fatal - 致命错误（程序会退出，谨慎使用）
if err := config.Load(); err != nil {
    logger.Fatal("config", "配置文件加载失败: %v", err)
}
```

## 💡 实战示例

### 示例 1：API 接口日志

```go
func CreateUser(c *fiber.Ctx) error {
    var req CreateUserRequest
    
    // 记录请求开始
    logger.Info("api", "创建用户请求开始")
    
    // 解析参数
    if err := c.BodyParser(&req); err != nil {
        logger.Error("api", "参数解析失败: %v", err)
        return c.Status(400).JSON(fiber.Map{
            "code": 400,
            "msg":  "参数错误",
        })
    }
    
    // 记录请求参数（注意：不要记录敏感信息如密码）
    logger.Debug("api", "请求参数: Username=%s, Email=%s", req.Username, req.Email)
    
    // 创建用户
    user := &model.User{
        Username: req.Username,
        Email:    req.Email,
    }
    
    if err := database.DB.Create(user).Error; err != nil {
        logger.Error("api", "创建用户失败: %v", err)
        return c.Status(500).JSON(fiber.Map{
            "code": 500,
            "msg":  "创建失败",
        })
    }
    
    // 记录成功
    logger.Info("api", "用户创建成功, ID: %d, Username: %s", user.ID, user.Username)
    
    return c.JSON(fiber.Map{
        "code": 200,
        "msg":  "创建成功",
        "data": user,
    })
}
```

### 示例 2：数据库操作日志

```go
func UpdateUser(userID uint, updates map[string]interface{}) error {
    logger.Info("db", "开始更新用户, ID: %d", userID)
    
    result := database.DB.Model(&model.User{}).
        Where("id = ?", userID).
        Updates(updates)
    
    if result.Error != nil {
        logger.Error("db", "更新用户失败, ID: %d, Error: %v", userID, result.Error)
        return result.Error
    }
    
    if result.RowsAffected == 0 {
        logger.Warn("db", "用户不存在或无变化, ID: %d", userID)
        return errors.New("用户不存在")
    }
    
    logger.Info("db", "用户更新成功, ID: %d, 影响行数: %d", userID, result.RowsAffected)
    return nil
}
```

### 示例 3：第三方 API 调用日志

```go
func SendSms(mobile, code string) error {
    logger.Info("sms", "发送短信, 手机号: %s", mobile)
    
    startTime := time.Now()
    
    resp, err := http.Post("https://api.sms.com/send", map[string]interface{}{
        "mobile": mobile,
        "code":   code,
    })
    
    duration := time.Since(startTime)
    
    if err != nil {
        logger.Error("sms", "发送失败, 手机号: %s, 耗时: %s, Error: %v", 
            mobile, duration, err)
        return err
    }
    
    if !http.IsSuccess(resp) {
        logger.Error("sms", "发送失败, 手机号: %s, 状态码: %d, 响应: %s", 
            mobile, resp.StatusCode(), resp.String())
        return errors.New("短信发送失败")
    }
    
    logger.Info("sms", "发送成功, 手机号: %s, 耗时: %s", mobile, duration)
    return nil
}
```

### 示例 4：定时任务日志

```go
func CleanExpiredCache() {
    logger.Info("job", "定时清理过期缓存任务开始")
    startTime := time.Now()
    
    // 获取所有过期的 key
    keys, err := cache.Keys("cache:*")
    if err != nil {
        logger.Error("job", "获取缓存key失败: %v", err)
        return
    }
    
    deletedCount := 0
    for _, key := range keys {
        ttl, _ := cache.TTL(key)
        if ttl < 0 {
            cache.Del(key)
            deletedCount++
        }
    }
    
    duration := time.Since(startTime)
    logger.Info("job", "定时清理任务完成, 删除: %d个, 耗时: %s", deletedCount, duration)
}
```

### 示例 5：错误追踪

```go
func ProcessOrder(orderID uint) error {
    logger.Info("order", "开始处理订单: %d", orderID)
    
    // 查询订单
    var order model.Order
    if err := database.DB.First(&order, orderID).Error; err != nil {
        logger.Error("order", "查询订单失败, ID: %d, Error: %v", orderID, err)
        return err
    }
    
    logger.Debug("order", "订单信息: %+v", order)
    
    // 检查库存
    if !checkStock(order.ProductID, order.Quantity) {
        logger.Warn("order", "库存不足, 订单: %d, 商品: %d", orderID, order.ProductID)
        return errors.New("库存不足")
    }
    
    // 扣减库存
    if err := deductStock(order.ProductID, order.Quantity); err != nil {
        logger.Error("order", "扣减库存失败, 订单: %d, Error: %v", orderID, err)
        return err
    }
    
    // 更新订单状态
    if err := updateOrderStatus(orderID, "paid"); err != nil {
        logger.Error("order", "更新订单状态失败, 订单: %d, Error: %v", orderID, err)
        // 回滚库存
        restoreStock(order.ProductID, order.Quantity)
        return err
    }
    
    logger.Info("order", "订单处理成功: %d", orderID)
    return nil
}
```

## 🔍 日志查询

### 查看日志文件

```bash
# 查看最新日志
tail -f logs/app.log

# 查看错误日志
tail -f logs/error.log

# 搜索关键词
grep "用户登录" logs/app.log

# 查看特定时间段
grep "2024-01-01" logs/app.log

# 统计错误数量
grep "ERROR" logs/app.log | wc -l
```

### 日志分析

```bash
# 统计最近的错误
tail -1000 logs/error.log | grep "ERROR" | cut -d']' -f2 | sort | uniq -c | sort -rn

# 查找慢查询
grep "耗时" logs/app.log | awk -F'耗时: ' '{print $2}' | sort -rn | head -10

# 统计API调用次数
grep "api" logs/app.log | cut -d']' -f3 | sort | uniq -c | sort -rn
```

## ⚠️ 最佳实践

### 1. 不要记录敏感信息

```go
// ❌ 错误：记录了密码
logger.Info("user", "用户登录: %s, 密码: %s", username, password)

// ✅ 正确：不记录密码
logger.Info("user", "用户登录: %s", username)
```

### 2. 使用合适的日志级别

```go
// ❌ 错误：普通操作用 Error
logger.Error("user", "用户查询, ID: %d", userID)

// ✅ 正确：普通操作用 Info
logger.Info("user", "用户查询, ID: %d", userID)
```

### 3. 记录足够的上下文

```go
// ❌ 错误：信息不足
logger.Error("db", "查询失败")

// ✅ 正确：包含详细信息
logger.Error("db", "查询用户失败, ID: %d, Error: %v", userID, err)
```

### 4. 避免过度日志

```go
// ❌ 错误：循环中记录日志
for _, user := range users {
    logger.Info("user", "处理用户: %d", user.ID)  // 1000次循环 = 1000条日志
}

// ✅ 正确：汇总记录
logger.Info("user", "开始批量处理, 总数: %d", len(users))
// 处理逻辑...
logger.Info("user", "批量处理完成, 成功: %d, 失败: %d", successCount, failCount)
```

### 5. 性能监控

```go
// 记录操作耗时
func QueryUsers() ([]model.User, error) {
    startTime := time.Now()
    defer func() {
        duration := time.Since(startTime)
        logger.Info("db", "查询用户完成, 耗时: %s", duration)
    }()
    
    var users []model.User
    err := database.DB.Find(&users).Error
    return users, err
}
```

## 📊 日志配置

### 配置文件

```toml
# config/config.toml
[logger]
level = "info"           # debug, info, warn, error
format = "json"          # json, console
output = "file"          # file, console, both
file_path = "logs/app.log"
max_size = 100          # MB
max_backups = 30        # 保留天数
compress = true         # 压缩旧日志
```

### 日志轮转

```go
// 自动按天分割日志
logs/
├── app.log              # 当前日志
├── app-2024-01-01.log   # 历史日志
├── app-2024-01-02.log
└── error.log            # 错误日志
```
